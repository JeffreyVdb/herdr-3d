# H3D Box

`h3d-box.woff2`: the box drawing (U+2500–257F) and block elements (U+2580–259F) of DejaVu Sans Mono 2.37
(`dejavu-fonts-ttf-2.37.zip` from github.com/dejavu-fonts/dejavu-fonts, release `version_2_37`, SHA-256
`7576310b…a908b0a`), subset with fontTools (`pyftsubset --unicodes=U+2500-259F --flavor=woff2 --layout-features=''
--no-hinting --desubroutinize`) and renamed "H3D Box", as the Bitstream Vera licence asks of a changed font
(`LICENSE`). The transcript's Quiet and Paper presets draw tool output's frames with it (`../quiet.css`,
`../paper.css`, #59).
