# Public token grammar sources

Retrieved 2026-10-18 through Alterlab MCP scrape/batch-scrape and asynchronous job retrieval. These are version-pinned public Gitleaks v8.30.1 generator rules, independent of the evaluated implementation. No repository or candidate-detector files were read. These grammars describe recognizable token shapes, not proof that generated strings are issued credentials. All evaluation strings must be locally generated synthetic values; never reuse source examples.

| Family | Generator shape / constraints | Pinned primary source |
| --- | --- | --- |
| AWS access key ID | `AKIA[A-Z2-7]{16}`; 20 characters total. The complete public rule also recognizes `A3T[A-Z0-9]`, `ASIA`, `ABIA`, `ACCA` prefixes with the same 16-character suffix, bounded by word boundaries. Entropy threshold 3; suffix `EXAMPLE` is allowlisted. | [AWS rule](https://github.com/gitleaks/gitleaks/blob/v8.30.1/cmd/generate/config/rules/aws.go) |
| GitHub classic PAT | `ghp_[0-9a-zA-Z]{36}`; 40 characters total; entropy 3. | [GitHub rules](https://github.com/gitleaks/gitleaks/blob/v8.30.1/cmd/generate/config/rules/github.go) |
| GitHub fine-grained PAT | `github_pat_\w{82}`; 93 characters total; entropy 3. For conservative generation use ASCII letters and digits, or 22 ASCII alphanumerics, underscore, 59 ASCII alphanumerics. | [GitHub rules](https://github.com/gitleaks/gitleaks/blob/v8.30.1/cmd/generate/config/rules/github.go) |
| OpenAI legacy | `sk-[a-zA-Z0-9]{20}T3BlbkFJ[a-zA-Z0-9]{20}`; 51 characters total; entropy 3. | [OpenAI rule](https://github.com/gitleaks/gitleaks/blob/v8.30.1/cmd/generate/config/rules/openai.go) |
| OpenAI current prefixed | `sk-(?:proj|svcacct|admin)-(?:[A-Za-z0-9_-]{74}|[A-Za-z0-9_-]{58})T3BlbkFJ(?:[A-Za-z0-9_-]{74}|[A-Za-z0-9_-]{58})`; choose equal flank lengths and end with alphanumeric for conservative generation. Rule adds boundary handling; entropy 3. | [OpenAI rule](https://github.com/gitleaks/gitleaks/blob/v8.30.1/cmd/generate/config/rules/openai.go) |
| Hugging Face access token | `hf_[A-Za-z]{34}`; 37 characters total. Prefix is lowercase and suffix is alphabetic, not numeric; entropy 2. | [Hugging Face rules](https://github.com/gitleaks/gitleaks/blob/v8.30.1/cmd/generate/config/rules/huggingface.go) |
| Slack bot token | Exact public rule: `xoxb-[0-9]{10,13}-[0-9]{10,13}[a-zA-Z0-9-]*`; entropy 3. A conservative complete specimen is `xoxb-` + 12 decimal digits + `-` + 12 decimal digits + `-` + 24 ASCII alphanumerics. | [Slack rules](https://github.com/gitleaks/gitleaks/blob/v8.30.1/cmd/generate/config/rules/slack.go) |
| Stripe secret/restricted key | `(?:sk|rk)_(?:test|live|prod)_[a-zA-Z0-9]{10,99}`; entropy 2. Prefer `sk_test_` with a 30-character ASCII alphanumeric suffix to avoid implying live issuance. | [Stripe rule](https://github.com/gitleaks/gitleaks/blob/v8.30.1/cmd/generate/config/rules/stripe.go) |
